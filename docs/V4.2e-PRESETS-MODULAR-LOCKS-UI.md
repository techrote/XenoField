## Modular global-preset locks

Global preset loading now respects physical UI submenus rather than being all-or-nothing.

Two-state submenu locks:
- `OFF`
- `LOCK`

A locked submenu is ignored only by global preset loads. Explicit edits and explicit panel-preset loads still work normally.

Three-state visual-panel overrides are available on SkySynth, Surface and LUT:
- `G:NONE` — honour individual submenu locks.
- `G:LOCK` — block global loads for every submenu in that visual panel.
- `G:UNLOCK` — force global loads through, temporarily overriding submenu locks.

Panel-global overrides never mutate the underlying submenu lock states. All lock state is persisted in project/browser state (`snapshot.version = 5`).

## UI layout changes

- SkySynth preview is now fixed above the scrollable SkySynth controls.
- Preset/source/synthesis/sampling controls scroll beneath the preview.
- Surface → Output profiler is in a sticky pinned header so it remains visible while the output controls scroll.
- Range tracks use a light-grey track and a hollow white circular handle in Chromium and Firefox.
