# XENOFIELD V4.3b — LUT Spatial Editor

V4.3b replaces the LUT window's flat 256-entry text grid with a dense 16×16 spatial editor while preserving the renderer-facing 256-colour LUT representation.

## Selection / clipboard

- Click-drag rectangular selection.
- Shift-drag adds regions; Ctrl/Cmd-drag toggles; Alt-drag subtracts.
- Select All / None / Invert / Row / Column.
- Shape-preserving region clipboard stores width, height, selection mask and colours.
- Copy/cut/paste works across LUT slots and offset destination selections.
- Plain text hex matrices are accepted from the native paste event; full 256-entry text remains compatible.
- Destination selections tile smaller clipboard regions while respecting sparse selection masks.
- Bounded 64-step undo/redo history covers direct cell edits, paste, cut, transforms, randomise, fill, gradients and brush strokes.

## Painting

- Dual colour A/B controls with native colour pickers, hex fields and swap.
- Eyedropper tool: left picks A, right picks B.
- Brush tool: left paints A, right paints B.
- Brush shapes: pixel, round, square, diamond and irregular.
- Brush sizes 1–5.
- Fill selected region with A.
- Horizontal, vertical, diagonal and radial A→B gradients over the selected region.
- Selection transforms: horizontal flip, vertical flip and 180° rotation.
- Double-click any cell for direct six-digit hex editing.

## UI

The LUT title bar now carries the high-frequency tools: Select, Brush, Pick, Undo, Redo, All, None, Copy, Cut and Paste. The colour/paint panel is packed beside the 16×16 grid so the editor remains usable without extra scrolling on a 1440p-class desktop.

## Compatibility

The LUT data model remains exactly ten banks × 256 `RRGGBB` entries, so existing renderer, panel-preset and global-preset behaviour is unchanged. V4.3a browser state is migrated to the V4.3b storage key with the ten palettes preserved.
