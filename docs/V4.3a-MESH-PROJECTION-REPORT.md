# XENOFIELD V4.3a — Mesh Import + Projection Mapping

## Scope
V4.3a generalises the projected-surface renderer from the sphere experiment into an arbitrary-mesh projection system.

## Mesh import / conditioning
- STL (binary / ASCII)
- OBJ
- ASCII PLY
- GLB 2.0
- self-contained / data-URI GLTF
- weld / normal rebuild
- adaptive edge-length retessellation
- curvature-driven subdivision
- boundary and hard-edge preservation
- optional smoothing
- spike detection with Leave / Relax / Clamp / Cull handling
- local edge-scale displacement safety
- automatic centring / normalisation

## Projection mappings
Implemented without geodesic mapping:
- Planar XY / XZ / YZ
- UV
- Spherical / lat-long
- Equal-area spherical
- Cubemap
- Octahedral
- Triplanar
- Cylindrical
- Radial
- Object-space 3D
- World-space 3D
- Tangent-local
- Camera projection
- Projector mapping
- Reflection-vector
- Polar-crush
- Axis-dominant
- Quantized-normal

Projection A/B blending, procedural projection masks, coordinate transforms, warp, quantization, drift, wrapping and per-layer projection overrides are integrated into the UI.

## Showcase presets
- `6 Economy Interactive` → built-in projection-knot mesh / Triplanar Volume.
- `5 Weather Engine` → exact user-supplied D20 STL / D20 Facet Storm.
- `7 Planetary Orbit` → existing visual stack, generalized projected sphere with Octahedral Planet mapping.

## Supplied D20
The exact uploaded `D20(2).stl` is packaged as `assets/D20-showcase.stl` and embedded byte-for-byte in the standalone build. The source contains 23,720 triangles. Its default showcase conditioning preserves engraved/bevel geometry and hard facet edges; retessellation remains available as an explicit option.

- Mesh and Projection tabs/preset banks are part of the existing modular lock/preset architecture.
