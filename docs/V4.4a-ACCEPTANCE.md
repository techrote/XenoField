## Explicitly not represented as completed measurements

There are no target-TITAN-RTX timings, browser GPU presentation screenshots, native MSAA8/16 modes, native AF32, closed-mesh SDF shells, explicit spectral/object motion vectors, unbounded infinite traversal, 3D cache slice editor or universal VRAM accounting. Optional physical scattering models and ABYSSAL world visibility were not reinstated.
