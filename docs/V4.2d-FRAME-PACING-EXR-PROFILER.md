# XENOFIELD V4.2d — frame pacing, large EXR and profiler pass

## Performance / sawtooth fix

The repeating SkySynth slowdown / catch-up cadence had two architectural characteristics that made it prone to visible pulses:

1. V4.2c-r2 blocked new rendering while `queue.onSubmittedWorkDone()` was outstanding. That forced the visible frame cadence to follow completion of every periodic SkySynth reconstruction submission.
2. SkySynth generation and reconstruction were encoded before the visible scene, so an expensive environment update delayed the same frame that was supposed to be presented.

V4.2d changes both:

- visible frames are no longer gated on `queue.onSubmittedWorkDone()`;
- queue-health synchronization is only sampled sparsely;
- the visible scene and postprocess are encoded before SkySynth generation/reconstruction;
- SkySynth missed ticks are dropped instead of accumulated, avoiding catch-up bursts;
- simulation delta is capped tightly during stalls rather than applying a large catch-up step;
- profiler painting is throttled to ~5 Hz and scheduled through `requestIdleCallback` where available;
- detailed JSON metric DOM updates are reduced to 1 Hz.

This is intended to preserve a steady 60 FPS presentation even while the environment pipeline updates periodically.

## Large EXR loading

- Maximum admitted file size: **2.6 GiB**.
- Maximum EXR data window: **30720 × 17280**.
- The local scanline decoder now downsamples during decode into the bounded HDRI map rather than first allocating a full-resolution RGBA32F image. This is important because a 30720×17280 RGBA32F buffer would exceed 8 GiB.
- Files above 256 MiB are deliberately not auto-cached into IndexedDB after loading, avoiding a second huge browser-storage copy.

## First-frame gate

GPU initialisation and the first rendered frame now require a click in the exposed render area. UI panels and preset selection remain usable before that click.

## UI changes

- All interface panels are fully opaque.
- Liquid tab buttons moved into the liquid panel title bar.
- The redundant `LIQUID` title label was removed.
- Liquid panel can be resized vertically from its bottom drag handle.
- Global preset controls remain in the main upper app bar.
- Global stacks include the LUT panel preset name.

## Performance profiler

The chart now includes:

- actual frame cadence in milliseconds;
- FPS on a separate 0 → FPS-limit axis;
- overlaid millisecond labels on every horizontal divider;
- top-right FPS-limit label and zero lower bound;
- larger readouts underneath;
- sparse WebGPU timestamp-query rolling averages where supported.

Timestamp-query stages include:

- GPU SkySynth source;
- GPU spatial smoothing;
- upsample A;
- NL filter;
- upsample B;
- mip generation;
- liquid FFT;
- scene render;
- postprocess;
- preview.

GPU timestamps are sampled roughly once per 60 rendered frames and smoothed, limiting profiler overhead. Browsers/adapters without `timestamp-query` continue to run normally and simply omit those measurements.
